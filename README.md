# Week 1 — HTML & CSS Personal Portfolio

A responsive personal portfolio built with semantic HTML5 and CSS3 only. No JavaScript or frontend framework is used.

## Sections
- Hero / introduction
- About
- Skills and interests
- Selected projects
- Contact links

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Resize the browser to test desktop, tablet, and mobile layouts.

## Publish with GitHub Pages
1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then click **Save**.
5. Wait for the published URL to appear in the Pages section.

## Before submitting
- Replace `your-email@example.com` in `index.html` with the email address you want to publish, or remove the email link.
- Check that the project descriptions accurately reflect your work.
- Confirm all sections fit on mobile and all links work.
- Submit both the repository URL and the GitHub Pages live URL.

## Technologies
- HTML5 (semantic elements, accessible labels and image descriptions)
- CSS3 (Grid, Flexbox, custom properties, responsive media queries, focus styles)
